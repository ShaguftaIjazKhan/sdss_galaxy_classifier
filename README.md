# SDSS DR7 Galaxy Classification Pipeline

An automated Python data analysis pipeline to parse, filter, and analyze morphological consensus data across 667,944 galaxies from the Sloan Digital Sky Survey (SDSS DR7).

## Summary of Results
- **Spiral Galaxies:** 83,791
- **Elliptical Galaxies:** 146,289
- **Uncertain / Mixed:** 584,153
- **Total Analyzed:** 667,944

## Tech Stack
- Python
- Matplotlib & Pandas
- Git & GitHub
